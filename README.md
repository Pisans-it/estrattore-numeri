# 🎲 Estrattore di Numeri Casuali

Applicazione web moderna, leggera e senza dipendenze per l'estrazione di numeri casuali.

## ✨ Funzionalità

- **Intervallo personalizzato**: Scegli liberamente il valore minimo (*Min*) e massimo (*Max*).
- **Quantità configurabile**: Estrai uno o più numeri contemporaneamente.
- **Esclusione numeri**: Rimuovi dall'estrazione specifici numeri (es. `3, 7, 13`) o intervalli (es. `20-25`).
- **Nessuna ripetizione**: I numeri estratti vengono rimossi dal sacchetto fino al reset.
- **Contatore in tempo reale**: Visualizza sempre quanti numeri rimangono disponibili nel pool.
- **Storico estrazioni**: Tieni traccia di tutti i numeri già usciti durante la sessione.
- **Interfaccia moderna e reattiva**: Design dark glassmorphism, responsive per smartphone, tablet e desktop.

## 🚀 Pubblicazione gratuita su GitHub Pages

1. Crea un nuovo repository su [GitHub](https://github.com/new) (es. `estrattore-numeri`).
2. Carica il file `index.html` nel repository.
3. Vai nelle **Settings** del repository -> sezione **Pages**.
4. Sotto **Build and deployment**, seleziona:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (o `master`) e cartella `/ (root)`
5. Clicca **Save**. Entro 1 minuto il tuo sito sarà online gratuitamente all'indirizzo:
   `https://<tuo-username>.github.io/estrattore-numeri/`
